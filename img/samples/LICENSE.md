# Licence of the images in this folder

The photographs in `img/samples/` are **not** covered by the AGPL that applies
to the source code of this app. They are licensed separately:

> Copyright netzbub (<https://github.com/netzbub>)
> Licensed under the Creative Commons Attribution 4.0 International License
> (CC BY 4.0) — <https://creativecommons.org/licenses/by/4.0/>

You may copy, redistribute, adapt and build upon them, for any purpose,
including commercially, provided you give attribution. The attribution the
licensor asks for is:

```
netzbub (https://github.com/netzbub), CC BY 4.0
```

CC BY 4.0 permits attribution by pseudonym (section 3(a)(1)(A) of the licence),
so this wording satisfies the licence; the legal name of the photographer is
not required.

This applies to every `.jpg` file in this folder. Each one carries the same
statement in its own metadata — `Artist`, `Copyright`, XMP `dc:creator`,
`dc:rights`, `xmpRights` and the Creative Commons `cc:` namespace — so the
licence travels with the file even when it is copied out of this app. No other
metadata is present: the images were re-encoded for this purpose, which removed
camera data, capture time, GPS coordinates and editing history.
